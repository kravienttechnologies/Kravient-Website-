# Bharat Connect

PROJECT NAME:

Kravient — Enterprise Technology / Offline-First Software Platform Website

PRIMARY GOAL:

Design and develop a premium, professional, enterprise-grade multipage website for “Kravient”, a software platform created by Praavi Group.

The website should feel inspired by the visual sophistication and UX philosophy of Persistent Systems:

https://www.persistent.com/

IMPORTANT:

DO NOT create a pixel-perfect clone or reuse Persistent branding/content/assets.

Instead, reproduce the same LEVEL OF:

- enterprise polish

- strong editorial typography

- section rhythm

- large storytelling blocks

- sophisticated navigation

- premium whitespace

- modular information cards

- image-driven storytelling

- dark/light contrast

- subtle motion

- confident corporate visual hierarchy

The final result must feel like a high-value technology company website suitable for a major client.
